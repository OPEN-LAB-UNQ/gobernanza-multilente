# Tipografía de presentación y detalle

Inter Variable, archivo oficial sin modificaciones, alojado en el propio sitio.
La página utiliza el alias CSS `Gobernanza Inter`, sin `local()` ni dependencias
de proveedores externos, para evitar sustituciones por instalaciones del equipo.
Se conservan los mismos contornos ópticos en todos los tamaños y se utilizan
pesos 400 (texto) y 600 (énfasis y títulos).
