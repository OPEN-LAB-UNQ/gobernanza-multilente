# Calibración 0.8.36

La variación intermensual solicitada exige meses consecutivos reconocidos. Conserva vacíos, excluye meses ambiguos y bases cero, registra las comparaciones excluidas y declara cobertura parcial. No describe caídas como incrementos. No cambia el control de sumas.

Trece casos de regresión: huecos presentes/ausentes en ambos órdenes, duplicados, trimestres, columnas sin fecha, cambio de año, descenso y base cero, incluyendo mezcla de trimestre y mes. Antes del cambio fallaron nueve casos. Se conserva el caso real de deuda con sus 91 variaciones.
